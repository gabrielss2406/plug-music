# Requisitos acordados

1. Windows 10 e 11.
2. MP3 definitivo somente no pendrive, temporário no computador.
3. Pesquisa com revisão e seleção antes de baixar.
4. Detecção de duplicatas SHA-256 + nomes; revisão humana.
5. Instalador `.exe` NSIS.
6. Gestão livre de pastas, inclusive mover/renomear/excluir.
7. Qualidade configurável (128/192/256/320 kbps).
8. Ao excluir, usuário escolhe recuperação ou exclusão definitiva.
9. Um pendrive ativo por vez.

Veja README para a diferença entre escopo e recursos já implementados.
